## Que es proyecto?
+ Esfuerzo temporal que se lleva a cabo crear un producto o servicio - PMI
+ Copmpromiso con objetivo definido, incluye metas de tiempo, costo y calidad - Asoc Admin Proyectos UK
### Un proyecto
+ Tiene objetivo bien definido y resultados
+ ejecuta mediante tareas interdependientes
+ requiere recursos para realizarse
+ Tiene un marco de tiempo especifico
---
+ Necesidad, problema, oportunidad
